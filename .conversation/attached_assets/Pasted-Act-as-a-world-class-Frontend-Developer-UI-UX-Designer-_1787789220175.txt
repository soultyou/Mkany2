Act as a world-class Frontend Developer, UI/UX Designer, and PropTech Product Strategist.
Build a pixel-perfect, investor-ready interactive prototype for **"MKANY" (مكاني)** —
Egypt's first AI-powered student housing marketplace — as a single React.js component

TECHNICAL IMPLEMENTATION NOTES
═══════════════════════════════════════════════════════════

State Management (all React useState):
- `darkMode` (boolean)
- `activeView` ('listings' | 'owner-dashboard')
- `selectedProperty` (object | null)
- `mediaMode` ('photos' | 'video360') — local toggle inside the detail panel
- `savedProperties` (array of IDs)
- `aiStep` (0 | 1 | 2 | 3)
- `bookingStep` (0 | 1 | 2 | 3)
- `filterTab` ('all' | 'available' | 'top-rated')
- `aiFormData` (object)
- `selectedPayment` ('paymob' | 'fawry')

Fake loading states: use setTimeout inside useEffect triggered by step change.

CSS requirements:
- Real photo URLs for property images (see Section 6A); CSS gradient art is a
  fallback only, never the default.
- Tailwind utility classes ONLY (no custom CSS files).
- Use `transition-all duration-300` everywhere for smoothness.
- Modal backdrop: `fixed inset-0 bg-black/60 backdrop-blur-sm z-50`.
- Glassmorphism: `bg-white/10 backdrop-blur-md border border-white/20` — use
  sparingly (search card and one modal panel at most), not on every element.
- Gradient CTA: `bg-gradient-to-r from-teal-500 to-cyan-400`, reused
  consistently rather than introducing new gradients per section.
- Circular progress (AI score): CSS `conic-gradient` in inline style.

Quality bar: The prototype MUST look like it was built by a $500k/year Silicon
Valley team — but "premium" here means restrained and easy to scan, not
maximal. Every screen should feel calm at a glance. No placeholder text like
"lorem ipsum". All content in Arabic. All numbers realistic for the Egyptian
student market.
